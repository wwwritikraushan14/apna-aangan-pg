# Apna Aangan PG — GitHub Pages DEMO version

This is the free demo edition of the Apna Aangan PG website. It runs fully on
GitHub Pages (no server needed).

## What works in this demo
- Homepage, rooms search/filters/sorting, property pages, gallery + lightbox
- Services & Amenities section (all 19 services)
- Pricing page with expense calculator and room comparison
- Call and WhatsApp buttons
- Enquiry and visit forms open WhatsApp with the details ready to send
- "Save" on a property page remembers the choice on that device only

## What does NOT work in this demo (needs the full server version)
- Enquiries/visits are not saved in a database
- No customer accounts, no admin panel
- Listings and prices are demonstration data (clearly labelled)

## How to put it live (free)
1. On GitHub, create a NEW public repository named: apna-aangan-pg-demo
2. Upload ALL files from this package into it, including the `images` and
   `icons` folders (GitHub: Add file -> Upload files).
3. In the repository: Settings -> Pages -> "Build and deployment" ->
   Source: Deploy from a branch -> Branch: main, folder: / (root) -> Save.
4. Wait 1-2 minutes. Your demo will be live at:
   https://wwwritikraushan14.github.io/apna-aangan-pg-demo/
